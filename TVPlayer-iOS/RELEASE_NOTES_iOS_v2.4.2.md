# TV go iOS v2.4.2

## 优化

- **切台转圈时也能看到加载反馈 / 网速**：此前切台正在转圈加载时，左上角网速徽标因瞬时网速为 0（直播分片下载间隙）一直显示 "--"，无法判断是在加载还是卡死。现改为：
  - 转圈/缓冲阶段若采到下载速度 → 显示真实网速（如 `850 KB/s`）。
  - 瞬时网速为 0 但仍在加载 → 显示「连接中…」；缓冲中 → 显示「缓冲中…」，出画后正常显示网速。
  - 数据层：AVPlayer 起播阶段网速采样不再被「单分片传输 >5s」排除（长分片慢 HLS 源），转圈时能采到真实的直播下载速度。

## 验证

- macOS runner（XcodeGen + xcodebuild archive，Release，CODE_SIGNING=NO）构建通过
- 切台转圈时左上角网速徽标有加载反馈；出画后正常显示网速
