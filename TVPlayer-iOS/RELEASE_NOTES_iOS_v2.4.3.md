# TV go iOS v2.4.3

## 修复

- **切台转圈时网速现在有真实数字**：此前切台正在转圈加载时，网速徽标因 AVPlayer 起播缓冲期 accessLog 无实时事件而显示 0 / "--"，用户无法看到源的下载活动。现改为：
  - **起播探测**：切台瞬间并行做一次轻量下载测速（预算 0.7s，下载源前若干 KB），把测得速度显示为转圈网速——用户能看到「真的在努力联网、有网速在动」；出画后由播放器真实采样覆盖。
  - **累计平均下载速率**：AVPlayer 起播阶段用 accessLog 累计字节/用时算出平均下载速率，比字节差分更早可用于显示。
  - **显示层**：转圈时优先显示真实网速数字；瞬时为 0 才显示「加载中…」；出画后正常。
  - 探测与预检是两次轻量请求，仅发生在起播一瞬，随即取消，对源压力极小。

## 验证

- macOS runner（XcodeGen + xcodebuild archive，Release，CODE_SIGNING=NO）构建通过
- 切台转圈时网速徽标显示真实下载速度（如 `850 KB/s`），出画后正常
