# TV go iOS v2.4.6

## 修复

- **切台转圈时「缓冲 X.Xs」不再被「加载中」闪烁覆盖**：v2.4.5 的缓冲秒数显示用的是瞬时缓冲值，直播分片下载间隙会瞬时掉回 0，导致「缓冲 X.Xs」只出现不到 1 秒就被「加载中」顶掉。现改为**转圈期间用缓冲峰值**（只增不减、单调增长）：
  - 转圈时显示「缓冲 X.Xs」，缓冲秒数随下载单调推进（0.5s → 1.2s → 2.5s → …），稳定反映「源在下载、缓冲在增长」。
  - 不会被分片间隙的瞬时 0 覆盖成「加载中」。
  - 出画后由 AVPlayer 实际字节速度接管，显示实时网速。

## 验证

- macOS runner（XcodeGen + xcodebuild archive，Release，CODE_SIGNING=NO）构建通过
- 切台转圈时「缓冲 X.Xs」单调增长，不闪烁；出画后显示实时网速
